# Changelog

All notable changes to `plan-ts-mode` are documented here.

## 1.0.0 - 2026-09-30

- Publish the mode for Emacs 29.1+ through `package-vc-install`.
- Include the Plan DSL tree-sitter grammar with reproducible macOS and Linux
  build and installation scripts.
- Provide highlighting, indentation, comments, navigation, imenu, and
  non-destructive format on save.
- Include an optional lsp-bridge configuration for `planq lsp`.
- Add isolated ERT, byte-compilation, corpus, and highlight test entry points.
